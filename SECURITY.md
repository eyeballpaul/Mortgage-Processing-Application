# Security Policy

## Supported versions

The `main` branch is the supported version of this demonstration project.

## Reporting a vulnerability

Do not open a public issue for a security vulnerability. Report it privately to the repository maintainers with:

- A description of the affected component
- Reproduction steps or a proof of concept
- The potential impact
- Any suggested mitigation

Do not include real personal, financial, or mortgage application data in reports. This project is a demonstration and must not be used to process real customer data without a separate security, privacy, and compliance review.
