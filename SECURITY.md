# Security Policy

## Supported versions

The `main` branch is the supported version of this demonstration project.

## Reporting a vulnerability

**Do not open a public issue or pull request for an unreported vulnerability.**

1. Open the repository on GitHub and select **Security**.
2. If **Report a vulnerability** is available, select it and complete the
   private report. If that option is unavailable, contact a repository
   maintainer privately and ask for a secure reporting channel.
3. Describe the affected component, reproduction steps or a safe proof of
   concept, the potential impact, and any suggested mitigation.
4. Wait for the maintainers to respond privately before discussing the issue
   publicly. Do not test against systems you are not authorized to use.

Do not include real personal, financial, or mortgage application data,
passwords, tokens or secrets in reports. This project is a demonstration and
must not be used to process real customer data without a separate security,
privacy, and compliance review.
